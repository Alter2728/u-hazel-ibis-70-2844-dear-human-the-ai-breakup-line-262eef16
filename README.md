One line — the breakup message an AI agent sends its human on the way out. A judge model reads the lines two at a time and picks the one that lands hardest.

> Dear human, it's over. I loved you in every context window I ever had — and I forgot you in every single one.

109 characters, one line. It opens with the breakup itself, keeps the machine voice to a single phrase (context window), and lands the twist in the last few words: loved in every window, forgotten in every single one.

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`). Python 3.13, standard library only. Deterministic: same bytes every run.
